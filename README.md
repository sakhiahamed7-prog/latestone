# Ledger

A small, dependency-free task list app for practicing Git.

## Structure

```
todo-app/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── app.js
└── README.md
```

## Run it

Just open `index.html` in a browser — no build step, no server required.
Tasks are saved to `localStorage`, so they persist between visits.

## Features

- Add tasks
- Mark tasks done / not done
- Remove tasks
- Clear all completed tasks
- Persists in the browser via localStorage
